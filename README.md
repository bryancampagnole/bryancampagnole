Gosto de criar **produtos completos**, do banco de dados à experiência de quem usa. Meu foco está em **aplicações web, APIs, automações e plataformas SaaS**, com atenção a escalabilidade, segurança e usabilidade.

- 🚀 Construindo o **[Condoxx OS](https://condoxx.com.br)**, uma plataforma de gestão condominial no ecossistema **Prediax**.
- 🧠 Interesses: arquitetura multi-tenant, integrações, produtos B2B e experiência do usuário.
- 🛠️ Gosto de conectar **tecnologia + produto + negócio**.
